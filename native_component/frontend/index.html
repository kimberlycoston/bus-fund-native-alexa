Try Native

Click Start Demo and allow microphone access.

Say the wake word “Hey Native,” wait for the chime, then start speaking normally. Note: The default language pair is English ↔ Spanish.

Try the following commands to interact with Native:

  1. If you want to change the language pair, say “Hey Native, choose languages”
    When prompted, say two languages—for example, "English and Arabic.” Native remembers your choice until you change it next.
  2. If you want to hear the most recent translation again, say “Hey Native, repeat please”
    Hear the most recent translation again.

Click Stop Demo to turn off the microphone.

For this demo, the button turns Native on and off. The intended bedside device would stay on in the patient’s room, listening for its wake word while in use.
